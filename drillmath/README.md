# Приём — тренажёр узнавания приёма

Отдельный сайт на **drillmath.archik.tech**: на карточке настоящая страница
билета IB, а приём надо назвать самому — найти его в каталоге из 286.
Решать не нужно; на экзамене вопрос приходит без подписи, из какой он темы,
и узнать приём это самая дорогая часть работы.

Раньше это был режим внутри атласа, одной вкладкой рядом с ещё четырьмя.
Экран там общий на все режимы, и под эту работу он не годился: каталог
приходилось втискивать в колонку с ответами, карточка оставалась далеко от
того места, куда смотришь. Здесь занятие одно, и экран устроен под него.

## Что здесь есть

- **Карточка** — страница билета из архива, обрезанная по самому вопросу
  (поле для письма занимает на листе две трети). Подпись называет сессию,
  бумагу и пункт; на телефоне страница открывается отдельной вкладкой, где
  работает зум.
- **Каталог** — вложенный: разделы силлабуса → темы → приёмы темы с их
  признаками узнавания. Поиск идёт поверх вложенности и по всем темам
  сразу, и по названию, и по признаку: вспоминают обычно признак.
- **Разбор** — ход самой схемы оценивания, строкой за строкой: это
  разметка конкретного вопроса, а не пересказ приёма. Рядом — второй
  способ, если схема его принимает, признак узнавания, ход приёма целиком
  и ловушки при ошибке.
- **Три вердикта**: верно, «рядом» (названный приём схема у этого вопроса
  упоминает, но ведёт вопрос другой) и мимо.
- **Итог занятия** — счёт, время и пары «назвали X вместо Y».
- **Тёмная тема** по системной настройке; страница билета в ней
  инвертируется, чтобы лист не светил белым.

## Чего здесь нет

Своего бэкенда. Сайт ходит в ту же службу, что и атлас, — `ib-drill` на
:8042, nginx проксирует `/api/drill`. Поэтому журнал, расписание и сила
приёмов общие: занятие, начатое здесь, видно на карте приёмов в атласе и
наоборот. Ручки описаны в `practicum/aahl/README.md`.

Остальных режимов тренажёра (узнавание, счёт, разбор письменной работы,
вечер) здесь тоже нет — они живут во вкладке «Повторение» атласа.

## Разработка

    npm install
    npm run dev          # 127.0.0.1:5174, /api/drill проксируется на 8042

Служба на 8042 — боевая, она же отвечает атласу. Чтобы не трогать боевой
журнал, поднимите свою рядом и укажите порт:

    PYTHONPATH=vendor/drill-core:practicum \
      DRILL_SUBJECTS=math:$PWD/practicum/aahl/subject.py \
      DRILL_DB=/tmp/drill-test.sqlite \
      python -m drill.server --port 8147
    DRILL_PORT=8147 npm run dev

## Выкатка

    sudo bash deploy/publish.sh

Сборка, релиз в `/var/www/drillmath.archik.tech/releases/<sha>-<дата>`,
подмена ссылки `current`. Конфигурация nginx — `deploy/drillmath.archik.tech.conf`,
на машине она лежит в `/etc/archik-sites/` и правится только от root;
копия здесь для того, чтобы в git было видно, что стоит на сервере.
Сертификат берёт `archik-certificates.timer`: список доменов он читает из
`server_name` живых сайтов, дописывать имя никуда не нужно.
